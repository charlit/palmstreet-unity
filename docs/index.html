PalmStreet

Un jeu de skate au cœur du Pays basque : d'Anglet à Biarritz la nuit, en passant par Bidart, Guéthary, Saint-Jean-de-Luz, Hendaye, Bayonne, Arcangues, Espelette, Ascain et Cambo-les-Bains.

Comment jouer

  • Toucher : ollie.
  • En l'air, glisser : une figure par direction.
  • Glisser vers le bas : se baisser (mouettes, ballons, pelotes).
  • Retomber sur un rail : grind ; glisser pour changer de grind.
  • Deux doigts : 180, passage en fakie (figures ×1,5).
  • Contre LE PELOTARI : maintenir le doigt pour le bouclier, glisser vers lui pour lancer la planche.
